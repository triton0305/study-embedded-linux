# Embedded Linux Study

C/C++와 Linux 기반 임베디드 소프트웨어 개발을 공부하며 작성한 실습 코드를 정리하는 저장소입니다.

단순 문법 학습에 그치지 않고, 이후 Raspberry Pi 기반 Embedded Linux 프로젝트에서 사용할 수 있도록  
Linux 개발 환경, C++, 네트워크 프로그래밍, 멀티스레딩, 빌드 시스템 등을 단계적으로 학습하는 것을 목표로 합니다.

## Study Environment

- Windows 11
- WSL2
- Ubuntu
- VS Code
- GCC / G++
- CMake
- GDB
- Git

## Directory Structure

```text
study-embedded-linux/
├── cpp/        # C++ 문법 및 STL, 멀티스레딩 실습

├── network/    # TCP/IP 및 Socket 프로그래밍
└── cmake/      # Makefile / CMake 빌드 실습
